# CapsHan

macOS에서 **Caps Lock으로 한/영을 바로 전환**하고, 전환할 때마다 **화면 아래 가운데에 현재 입력 언어를 잠깐 보여 주는** 메뉴 막대 앱이에요.

- macOS 기본 Caps Lock 한/영 전환에 있는 지연이 없어요.
- 한/영이 바뀌면 `가 한글` / `A 영어` 팝업이 잠깐 떴다가 사라져요(기본 0.8초). Caps Lock뿐 아니라 메뉴 막대 등 어떤 방법으로 바꿔도 떠요.
- 팝업은 리퀴드 글래스(macOS 26 이상) 또는 클래식 디자인 중에 고를 수 있고, 다크 모드를 따라가요. 리퀴드 글래스는 유리 질감과 강도, 팝업 크기로 느낌을 조절할 수 있어요.
- 팝업은 마우스 포인터가 있는 화면에 떠요.
- 메뉴 막대 아이콘이 지금 입력 언어(`한` / `영`)를 보여 주고, macOS 기본 입력 메뉴는 숨길 수 있어요.
- macOS 13 Ventura 이상용으로 빌드되고, Apple Silicon과 Intel을 모두 지원해요. macOS 26 Tahoe에서 테스트했어요.

## 설치

1. [Releases](https://github.com/Moooooomin/CapsHan/releases)에서 최신 `CapsHan-<버전>.dmg`를 받아 열고, **CapsHan**을 **응용 프로그램** 폴더로 끌어다 놓아요.
2. 응용 프로그램 폴더에서 CapsHan을 실행해요.
   - "확인되지 않은 개발자" 경고가 뜨면 **시스템 설정 → 개인정보 보호 및 보안**으로 가서 맨 아래 CapsHan 항목의 **"그래도 열기"**를 눌러요. (Apple 개발자 서명이 없는 빌드라서 처음 한 번만 필요해요.)
3. 설정창이 열리면 끝이에요. 응용 프로그램 폴더에서 실행하면 로그인할 때 자동으로 실행돼요.

CapsHan이 Caps Lock 키 자체를 F18로 바꾸기 때문에, macOS의 **"Caps Lock 키로 ABC 입력 소스 전환"** 옵션(시스템 설정 → 키보드 → 입력 소스 → 편집)은 더 이상 쓰이지 않아요. 꺼 두는 걸 권장해요.

## 설정창

앱 서랍(Launchpad)이나 응용 프로그램 폴더에서 **CapsHan을 누르면** 설정창이 열려요. 메뉴 막대의 ⌨︎ 아이콘 → **설정…**(⌘,)으로도 열 수 있어요. 로그인할 때 자동으로 실행될 때는 설정창이 뜨지 않아요.

| 항목 | 설명 |
| --- | --- |
| 한/영이 바뀌면 팝업 표시 | 화면 아래 팝업 켜기/끄기 |
| 표시 시간 | 팝업이 떠 있는 시간 (0.3~3.0초, 0.1초 단위) |
| 팝업 크기 | 80~160%. 클수록 리퀴드 글래스의 굴절이 잘 보여요 |
| 테마 | 시스템 설정(다크 모드 따라감) / 라이트 / 다크 |
| 디자인 | 리퀴드 글래스 / 클래식(반투명 블러). 리퀴드 글래스는 macOS 26 이상 |
| 유리 질감 | 반투명 / 맑은 유리. 맑은 유리가 뒤 배경이 더 비치고 리퀴드 느낌이 강해요 (리퀴드 글래스일 때) |
| 리퀴드 강도 | 0~100%. 낮출수록 흰색·검은색 틴트가 덮여 젖빛 유리처럼 되고, 100%면 틴트 없는 유리예요 (리퀴드 글래스일 때) |
| 팝업 미리보기 | 지금 설정으로 팝업을 띄워 봐요. 테마·디자인·표시 시간을 바꿔도 자동으로 보여 주고, 강도·크기 슬라이더는 끄는 동안 실시간으로 보여 줘요 |
| 메뉴 막대 아이콘 | `한 / 영`, `한 / A`, 키보드 모양 중에 골라요 |
| macOS 기본 입력 메뉴 숨기기 | 메뉴 막대의 기본 한/A 아이콘을 숨겨요. CapsHan 메뉴나 설정창에서 종료하면 다시 보여요 |
| Caps Lock으로 한/영 전환 | 끄면 Caps Lock과 "이전 입력 소스 선택" 단축키가 원래대로 돌아가요 |
| 로그인 시 자동 실행 | 시스템 설정 → 일반 → 로그인 항목에 등록/해제 |

메뉴 막대의 CapsHan 아이콘을 누르면 입력 소스 목록(ABC, 두벌식 등)이 나와서, 기본 입력 메뉴를 숨겨도 여기서 입력 소스를 고를 수 있어요. 그 아래에 설정…, 팝업 미리보기, 종료가 있어요.

설정창은 시스템 SwiftUI 폼으로 만들어서 macOS 26에서는 리퀴드 글래스 스타일로 표시돼요. ⌘W로 닫을 수 있어요(닫아도 앱은 계속 실행돼요).

## 동작 방식

1. Caps Lock 키를 **F18**로 리매핑해요 (`hidutil`과 같은 IOKit API를 써요). 그래서 macOS가 Caps Lock에 두는 판단 지연이 생기지 않아요. 대신 대문자 고정 기능은 사라지니 대문자는 Shift로 쳐요.
2. 시스템 단축키 **"이전 입력 소스 선택"**을 F18로 바꾸고, 다시 로그인하지 않아도 바로 적용되게 해요.
3. 입력 소스가 바뀌었다는 시스템 알림을 받으면 팝업을 띄우고 메뉴 막대 아이콘을 바꿔요.
4. "기본 입력 메뉴 숨기기"를 켜면 macOS의 "메뉴 막대에서 입력 메뉴 보기" 설정을 끄고 입력 메뉴 프로세스(TextInputMenuAgent)를 다시 띄워서 바로 적용해요.

키 리매핑은 재시동하면 풀리기 때문에, 앱이 실행될 때마다 다시 적용해요. 다른 키 리매핑을 쓰고 있다면 Caps Lock 항목만 바꾸고 나머지는 그대로 둬요.

2번의 "바로 적용"에는 시스템 설정 앱이 쓰는 비공개 API(`CGSSetSymbolicHotKeyValue`)를 써요. 그래서 Mac App Store에는 올릴 수 없고, 앞으로 macOS 업데이트에서 동작이 바뀔 수도 있어요. 이 경우에도 단축키 설정 자체는 저장되기 때문에 다시 로그인하면 적용돼요.

## 개인정보

CapsHan은 네트워크를 전혀 쓰지 않고, 아무 데이터도 수집하거나 보내지 않아요. 설정은 이 Mac의 사용자 설정(`~/Library/Preferences/io.github.moooooomin.capshan.plist`)에만 저장돼요. 손쉬운 사용, 입력 모니터링, 화면 기록 같은 권한도 요구하지 않아요.

## 제거

1. 설정창에서 **"Caps Lock으로 한/영 전환"**과 **"macOS 기본 입력 메뉴 숨기기"**를 꺼요. 그러면 Caps Lock, 단축키, 기본 입력 메뉴가 원래대로 돌아가요.
2. 설정창이나 메뉴 막대 아이콘에서 **CapsHan 종료**를 누른 다음, 응용 프로그램 폴더에서 CapsHan을 휴지통으로 옮겨요.

1번을 건너뛰고 지웠다면, 단축키는 시스템 설정 → 키보드 → 키보드 단축키 → 입력 소스에서 직접 되돌리면 돼요. 기본 입력 메뉴는 시스템 설정 → 키보드 → 텍스트 입력의 입력 소스 "편집…"에서 "메뉴 막대에서 입력 메뉴 보기"를 켜면 돼요. Caps Lock은 재시동하면 원래대로 돌아와요.

## 빌드

Xcode 없이 Command Line Tools만 있으면 돼요.

```bash
./build.sh
```

결과물은 `build/CapsHan.app`과 `dist/CapsHan-<버전>.dmg`이에요. 환경 변수로 값을 바꿀 수 있어요.

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `BUNDLE_ID` | `io.github.moooooomin.capshan` | 번들 ID. 포크해서 따로 배포한다면 본인 것으로 바꿔 주세요 |
| `VERSION` | `1.3.0` | 표시 버전 |
| `BUILD_NUMBER` | `4` | 빌드 번호 |
| `SIGN_IDENTITY` | (없음, ad-hoc 서명) | `Developer ID Application: …` 인증서 이름 |

### 경고 없이 배포하려면

다른 사람이 "확인되지 않은 개발자" 경고 없이 열게 하려면 Apple Developer Program(유료) 계정으로 서명하고 공증해야 해요.

```bash
SIGN_IDENTITY="Developer ID Application: 이름 (TEAMID)" ./build.sh
xcrun notarytool submit dist/CapsHan-<버전>.dmg --keychain-profile <프로필> --wait
xcrun stapler staple dist/CapsHan-<버전>.dmg
```

## 파일 구성

```
Sources/
  main.swift            앱 시작, 메뉴 막대, 입력 소스 변경 감지
  Settings.swift        설정 값(UserDefaults)
  SettingsWindow.swift  SwiftUI 설정창
  HUD.swift             화면 아래 팝업 (리퀴드 글래스 / 클래식)
  MenuBar.swift         메뉴 막대 한/영 아이콘, 기본 입력 메뉴 숨기기
  InputSource.swift     현재·선택 가능한 입력 소스, 표시 글자/이름
  CapsLockSwitch.swift  Caps Lock → F18 리매핑, 시스템 단축키 변경
  LoginItem.swift       로그인 시 자동 실행, 로그인 실행 여부 판단
Resources/Info.plist    번들 정보 (build.sh가 값을 채워요)
scripts/make-icon.swift 앱 아이콘 생성
build.sh                빌드 + 서명 + DMG
```
